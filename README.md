# 🎓 منصة خدمة وتذاكر الطلبة الذكية - جامعة الإمام الكاظم (ع) للعلوم الإسلامية الجامعة

منظومة إلكترونية متكاملة تتيح لطلبة جامعة الإمام الكاظم (ع) التواصل المباشر مع الكادر التدريسي (الأساتذة ورؤساء الأقسام) والإدارة (معاون العميد لشؤون الطلبة، المعاون العلمي، شعبة التسجيل، الحسابات) عبر **نظام غرف التذاكر الفورية (Discord-like Ticket Rooms)** مع التحقق من الهوية الجامعية.

---

## 🌟 الميزات الأساسية للمشروع:

1. **نظام التذاكر المباشر (مثل الديسكورد):**
   * فتح غرفة محادثة مشفرة ومخصصة لكل استفسار أو مشكلة بين الطالب والجهة المعنية فقط.
   * إشعار فوري وتحديث حي للرسائل عبر تقنية **WebSockets (Socket.IO)** بدون الحاجة لإعادة تحميل الصفحة.
   * مؤشر كتابة مباشر (*"الدكتور يكتب الآن..."*).
   * إمكانية إرفاق الصور والملفات والوثائق الرسمية داخل المحادثة.
   * حالات التذكرة: (🟡 مفتوحة - 🔵 قيد المعالجة - 🟢 تم الحل والإغلاق).

2. **التسجيل والتحقق من هوية الطالب:**
   * تسجيل الدخول المباشر برقم هوية الطالب الجامعية (`Student ID Number`).
   * تسجيل طالب جديد مع رفع صورة الهوية الجامعية.
   * لوحة تحكم خاصة لشؤون الطلبة والإدارة لمراجعة صورة الهوية واعتماد الحساب رسميًا أو رفضه.

3. **لوحة تحكم الكادر التدريسي والإدارة:**
   * استعراض التذاكر الموجهة لكل دكتور أو معاون أو قسم.
   * إمكانية تغيير حالة التذكرة وحلها وإغلاقها.

4. **تصميم متجاوب بالكامل (Mobile-First):**
   * واجهة عربية RTL فائقة السلاسة والأناقة بهوية جامعة الإمام الكاظم (ع).
   * متوافقة 100% مع شاشات الهواتف الذكية والأجهزة اللوحية والحواسيب.
   * جاهزة للتحويل إلى تطبيق Android و iOS أصلي عبر تقنية **Capacitor**.

## 📱 خطوة تحويل الموقع إلى تطبيق هاتف (Android & iOS):

بعد اكتمال الموقع، يمكن تحويله إلى تطبيق موبايل بكود واحد باستخدام **Capacitor**:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "جامعة الإمام الكاظم" "iq.edu.alkadhim.portal" --web-dir client/dist
npx cap add android
npx cap open android
```
وسيكون تطبيقك جاهزاً للعمل كـ APK وتثبيته على أي هاتف!
